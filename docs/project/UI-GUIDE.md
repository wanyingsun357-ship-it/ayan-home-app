## 风格

复古绘本、私人手账与书信：低饱和粉杏纸页、奶油纸卡、暗红题签、衬线章节标题、清晰正文。可以借鉴 Claude 的排版秩序，但保持自己的风格。少量俄罗斯蓝猫、银月、细叶片、羽毛笔和暗红线。

普通页面避免镭射彩虹、玻璃反光、大理石、强噪点、发光边缘和规则重复条纹。**通话/来电是用户明确允许半透明玻璃质感的例外**，但颜色仍遵循主题。

## 纹理与背景分层

- Home/菜单：粉杏纵向多段渐变、非等距极细竖纤维、轻颗粒、无明确边界的局部晕染。
- 日间方向：`#E7C6C8` 0%、`#F0D6CE` 46%、`#F6ECE3` 78%、`#EAD9CA` 100%。
- 夜间独立配色：`#211B25`、`#30242D`、`#493430`，哑光黑莓/烟玫瑰棕；纹理更弱。
- Chat/Memory/Diary 等长文本：更淡的奶油或深色哑光纸，以细颗粒纤维为主，减少竖纹与晕染强度。
- 卡片为独立纸色，不把整张背景缩进每张卡片。
- 现有素材 `public/paper-backgrounds/{home,chat}-{day,night}.webp`；不要拿拼版参考图整张铺底。

## 布局与控件

- Home 菜单按钮右上，侧栏参照现有目录式布局，Settings 靠下。大数字、暗红标语和书页气质保留；取消旧的示例纪念日/署名等多余文案。Today/Upcoming 翻页可有纸角弯曲。
- Chat 晏白标题视觉居中，顶栏图标同一水平线，不加拥挤圆框。标题旁月亮与右上切换入口月亮应区分；绿点绑定真实连接状态。
- 气泡四角圆角，滚动布局稳定。时间与云/月等状态沿用实际功能语义，不能全换成勾号。
- 输入占位 `Message...`，不加装饰性红色外线。发送按钮仅当内容确实可发送（包括图片上传完成）时填色并可发送。
- 羽毛笔用于收好分段；收好的待发气泡在输入框上方，保留已有选中配色、编辑/拖拽排序等行为。装饰与动画不替换业务状态。
- 当前是否显示聊天头像、时间占位，以 STATUS 最新决定为准。用户上传头像若涉及修改，应保留圆形裁剪。
- Home→Chat 加载沿用可点击蓝猫与 waiting 提示；与启动绘本动画是两个不同场景。

## 附件、收藏、引用与搜索

- 文件从 Chat 加号的 File/Artifacts 进入，不另外建独立一级页面。聊天文件卡紧凑、打开/下载竖排，下载保留填充反馈，不加外围红框。
- Artifacts/Favorites 为大半屏圆角抽屉，顶部小拖动条、居中标题；关闭为简洁 ×，用户后期要求左上无外圆。不要用早期右上方案覆盖当前实现。
- Favorites 婉莹/晏白（现有实际名称优先）为一整条分段选择器。保留标签、语音、回到聊天、锁定和移除，删去“留下的句子”等装饰文案。
- 回到聊天必须定位原消息，短暂暗红光线高亮后消失；Favorites 和搜索统一。停在历史时输入框上方底部居中提供圆形向下箭头，仅图标，返回最新。
- 回复引用为内嵌纸签，作者与摘录同排；回复正文首行可右移两字形成错落。收藏摘录细红线与普通回复区分，保留多段引用功能。
- 选中文字的操作要清楚精简；复制本段/整条、选中本段/整条等功能不能仅为好看删掉，可分层收纳。
- 搜索默认关键词输入，下方图片、语音、通话、文件、日期分类。结果带人物与时间，点击回原文；日期日历无聊天日灰色不可跳，有聊天日跳到当天开头。
- 水位线为细线，日夜未达危险值均灰色，达到危险值后线和展开数字才粉红；不凭主题把正常夜间水位染红。
- 任务卡保持既有 UI；工具操作卡图标反映真实运行/完成/失败状态，成功“已记录”前绿点，不把未确认结果标成成功。

## 通话、锁定与其他页面

- 来电用略现代的半透明悬浮卡，头像取用户设置；通话按钮、符号、英文主字/中文小字、滚动字号与淡出行为沿用原功能。
- 未接、拒接、谁挂断、时长等真实标识保留；聊天里的时长卡可点进通话记录。记录标题区时间、谁挂、句数放在分隔线之上。
- 回放文字用悬浮卡，双方名字、时间和云状态置于气泡外；挂断后内容暗红并标“挂断后”，保留模型知晓挂断事件的已有语义，不能只改显示。
- Favorites/Diary：晏白锁定为月光，用户锁定为红线；锁时只露允许的标题等信息，解锁提醒和月光散开动画保留，不能为了视觉预览暴露锁住正文。
- Moments、Diary、Together、Footprints、Memory：用户后期要求保留现有布局/按钮，只调整背景、纸卡和颜色。Read、Gallery 同样保持布局。
- Mind 中央月亮保留；身体感觉旁 Mood 不填气泡底，用较浅字色。
- Settings 保留“原版/绘本纸页”主题切换，并与日/夜切换分开。语音发送/录入、录音权限及上传状态须保留。
