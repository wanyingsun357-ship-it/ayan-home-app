# 阿晏项目：新会话入口

开始本项目工作前，读取以下交接文档：
1. `home/docs/project/STATUS.md`：最后核实版本、已完成、待办和冲突决策。
2. `home/docs/project/UI-GUIDE.md`：用户确认的视觉风格与必须保留的交互。
3. `home/docs/project/HANDOFF.md`：目录、代码来源、验证和发布方式。

这些是项目交接记录，不表示新会话继承了旧聊天全文。用户的新指令优先；文档中的版本、完成状态和授权记录必须结合当前任务及实际代码核实。

最重要：`home/src`、各 `release-*` 和 `design-preview` 可能过期。先核对线上源码和未提交修改，保护其他窗口刚做的改动。只修改任务相关文件，不整目录覆盖线上。不要读取或输出密钥文件来做常规交接。

完成有意义的修改后更新 STATUS：记录完成/验证/部署状态、已知问题和下一步。改变视觉决定时同步 UI-GUIDE；不把讨论过的设想写成已经实现。
