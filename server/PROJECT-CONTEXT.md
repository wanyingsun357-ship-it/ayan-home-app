# Project context synchronization

`project-context.cjs` loads every top-level Markdown document from the conversation's current Project. Global identity/rules keep their existing loader. Source document files are never modified. An engine/thread-specific private hash acknowledgement avoids resending unchanged documents; failed turns remain pending. Entering, leaving, editing and compaction refresh the state. Moving out stops current project loading and emits an explicit inactive state; previous chat history is retained, so this is not a history eraser or filesystem access-control boundary.

The integration patch applies to the matching private bridge sources under `/root/ayan/bridge` (baseline and post-deploy hashes are retained in the private deployment backup). It wires Claude's real prompt input, Codex `turn/start.additionalContext`, post-success acknowledgements, compaction invalidation and atomic transcript moves. The installed Codex 0.162.0 requires the experimental capability for additionalContext; the opt-in is scoped to the chat runner. Re-test protocol support before upgrading the CLI. Resumed thread developerInstructions and Claude append-system-prompt alone did not update the old sessions in the integration tests.

Do not copy private CLAUDE.md/project documents, state, logs, transcripts, credentials, staging baselines or deployment bundles into this repository. Runtime state contains only schema/version hashes and lives in the private bridge directory. Existing target transcripts are backed up privately before replacement. Moving a conversation during a running reply returns 409; copy failure preserves its previous membership.

Local unit/compaction tests: `node --test server/project-context.test.cjs server/project-context-compact.test.cjs`. Protocol tests require installed Codex and Claude CLIs: `node --test server/project-context-protocol.test.cjs`. These tests use synthetic documents, temporary CODEX_HOME/CLAUDE_CONFIG_DIR directories and loopback mock inference only; they do not call paid models. Route tests read the installed bridge source (override AYAN_PROJECT_BRIDGE_SOURCE when needed) and run the extracted handler against synthetic state, never the production API. The original 20k retained-chat budget and image/tool-result handling remain intact; only injected project snapshots are removed from retained raw conversation text.

The public repository uses ES modules by default. The two dependency mirrors are named `codex-rpc.cjs` and `compact-transcript.cjs` for standalone tests; the deployment patch retains the private bridge runtime filenames ending in `.js`.
